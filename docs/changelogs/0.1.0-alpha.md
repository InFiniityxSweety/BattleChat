# BattleChat 0.1.0-alpha

Initial BattleChat alpha based on ChatPlus for Fabric / Minecraft 26.2.

## Added
- Semantic `Chat` and `Server` message routing with modern metadata and legacy/ViaVersion fallback classification.
- `Any`, `Player`, and `Server` message-source selection for tabs.
- `Ctrl + right click` Message Info diagnostics with classifier type, confidence and reason.
- Reliable manual incoming translation via `Ctrl + left click` with German as the default target.
- Outgoing translation toggle with selectable language and green active state.
- Multi-provider translation fallback chain with retries, provider-local cooldowns and caching.
- Translation-aware Unicode text styles: Enchantment, Small Caps, Fullwidth, Bold, Italic, Bold Italic, Monospace, Fraktur, Double Struck, Script, Circled and Upside Down.
- Emoji picker with search, categories, recent entries, favorites and cursor insertion.
- Dedicated BattleChat configuration directory with one-time compatible ChatPlus import.
- `/battlechat` client command while retaining the existing ChatPlus aliases for compatibility.

## Changed
- Public build metadata and visible local messages use BattleChat branding.
- Incoming messages are never translated automatically; translation is explicitly user-triggered.
- Slash commands bypass outgoing translation and text transformations.

## Compatibility
- Internal ChatPlus package/resource names remain where changing them would risk mixin, access-widener or asset compatibility.
- GPL-3.0 licensing and upstream attribution are preserved.
