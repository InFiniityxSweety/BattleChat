# BattleChat

BattleChat is a client-side Minecraft chat enhancement mod based on ChatPlus, targeting Fabric 26.2 first.

## Current 0.1.0-alpha development goals

- reliable manual incoming translation via Ctrl + left click
- outgoing translation mode with visible green enabled state and selectable target language
- resilient translation provider fallbacks and provider-local cooldowns
- semantic `Chat` / `Server` tabs with modern message metadata and legacy/ViaVersion fallback classification
- emoji picker
- additional text transformations, including Minecraft Enchantment / Standard Galactic Alphabet style

## Upstream
